## 什么是飞书卡片

飞书卡片是应用的一种能力，包括构建卡片内容所需的组件和发送卡片所需的能力，并提供可视化搭建工具（`open.feishu.cn/cardkit`）。

飞书卡片能够将结构化的内容以卡片形式嵌入至聊天消息、群置顶消息、链接预览等飞书协作场景中，提升信息传递效率。用户可以在卡片上通过简单交互完成业务处理，让业务系统触手可及。

> 核心价值：使应用的使用体验从"人找应用"，演变为"应用找人"。

## 五大功能特性

| 特性 | 说明 |
|------|------|
| **结构化** | 灵活的布局能力和丰富的图文呈现组件，更结构化地组织卡片内容 |
| **嵌入式** | 嵌入至聊天消息、群置顶、链接预览等飞书协作场景 |
| **轻交互** | 支持"点一下就提交"的轻量交互，如工单审批、活动报名、表单填写 |
| **数据可视化** | 提供图表组件，支持柱状图、折线图、饼图等 |
| **多场景复用** | 卡片模板 + 变量功能，同一模板多场景复用 |

## 三大应用场景

### 1. 消息场景

| 子场景 | 说明 | 示例 |
|--------|------|------|
| 静态内容推送 | 文本/图片/图表等静态展示 + 打开链接按钮 | 行业资讯、销售排行、生日祝福、监控告警 |
| 动态内容交互 | 卡片中"点一下就提交"，接收用户数据并响应 | 工单审批、活动报名、表单填写 |
| AI 机器人 | 流式更新卡片、增删改组件，实时交互 | AI 对话流式回答 |

### 2. 消息链接预览场景

飞书卡片与链接预览能力关联，使特定链接通过卡片实现内容预览，用户不跳转即可洞察链接信息。

### 3. 群置顶卡片场景

飞书卡片支持在飞书会话的置顶消息中展示。

## 基础概念

| 概念 | 说明 |
|------|------|
| **卡片模板** | 基于卡片搭建工具创建的卡片 |
| **卡片模板 ID**（`template_id`） | 每个卡片模板的唯一 ID，搭建工具自动生成 |
| **卡片实体** | 基于创建卡片实体接口创建的卡片 |
| **卡片实体 ID**（`card_id`） | 卡片实体的唯一标识，用于发送/更新卡片 |
| **卡片案例** | 搭建工具参考案例库中的卡片案例 |

## 使用教程路径

| 阶段 | 推荐文档 |
|------|---------|
| 阶段一：了解与入门 | 开发一个卡片交互机器人 / 使用指定应用发送卡片 / 使用自定义机器人发送卡片 |

## 发送卡片方式对比

| 方式 | 适用场景 | 教程 |
|------|---------|------|
| 无代码发送 | 一次性活动推广卡片 | 搭建工具直接发送 |
| 自定义机器人 | 定期社群通知 | 自定义机器人 + Webhook |
